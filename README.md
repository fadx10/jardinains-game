# Jardinains!

## Retro Brick Breaker Arcade Game

Jardinains! is a browser-based remake of the classic brick breaker arcade experience, featuring 1,000 retro levels, mischievous garden nains to juggle, power-ups, synth-inspired sounds, and full-screen play.

The project is built as a React + TypeScript application and compiled with Vite into a standalone production bundle that can be served directly from shared web hosting.

## Features

- 1,000 retro brick-breaker levels
- Classic arcade-style paddle and ball gameplay
- Mischievous garden nains that can be bounced and juggled
- Power-ups and arcade gameplay elements
- Synth-inspired game audio
- Responsive browser experience
- Full-screen gameplay support
- Progressive Web App metadata and manifest support
- SEO-friendly page metadata and social sharing tags
- Standalone production build for conventional Apache/LiteSpeed hosting

## Run Locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The Vite development server is configured to listen on port `3000` and on `0.0.0.0`. fileciteturn2file0

## Production Build

Create the production build with:

```bash
npm run build
```

The Vite configuration builds from `index.source.html`, produces a standalone bundle, and synchronizes the compiled application to both `dist/index.html` and the repository root `index.html`. Supporting files such as `.htaccess`, `favicon.svg`, and `manifest.json` are also copied into `dist/`. fileciteturn5file0

To preview the production build locally:

```bash
npm run preview
```

To run the TypeScript check:

```bash
npm run lint
```

## Deployment

The project is designed for deployment to shared hosting environments such as Hostinger/cPanel using Git Version Control.

The deployment configuration copies the compiled `dist/index.html` (with a fallback to the root `index.html`), `.htaccess`, public assets, the favicon, and the PWA manifest into the configured deployment directory. fileciteturn7file0

For shared hosting deployments, build the project before pushing changes so the repository contains the latest compiled production bundle. The project deployment instructions explicitly require the compiled output to be available for the server because shared hosting serves the generated static files rather than compiling the React/TypeScript source on demand. fileciteturn4file0

## Gameplay

Jardinains! is designed around the familiar brick-breaker formula: control the paddle, keep the ball in play, break through level layouts, collect useful power-ups, and deal with the game's mischievous garden nains.

For the best experience, use a desktop browser or a mobile device with a sufficiently large display, and switch to full-screen mode when available.

## Development Notes

The project uses a two-file HTML architecture:

- `index.source.html` is the master source template for HTML metadata, SEO, fonts, and related page-level configuration.
- `index.html` is the generated standalone production bundle.

Do not modify the generated `index.html` directly. Make source-level changes and run the production build so the generated bundle stays synchronized. fileciteturn4file0

The Vite configuration also includes development support for the source HTML template and a production plugin that keeps the compiled root bundle synchronized. fileciteturn5file0
