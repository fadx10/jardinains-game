# CRITICAL SYSTEM INSTRUCTIONS FOR GEMINI / AI CODING ASSISTANTS

## 🚨 PERMANENT HOSTING & BUILD ARCHITECTURE (DO NOT ALTER)

This project runs live on **Hostinger Shared Web Hosting (Apache/LiteSpeed)** at `https://digitalphablet.com/jardinains/`.
Shared hosting environments serve static files directly and **CANNOT run Node.js build processes at runtime**.

### Key Rules:
1. **Source Template:** `index.source.html` is the only source HTML template. All `<head>`, `<title>`, `<meta>`, fonts, and script configurations belong in `index.source.html`.
2. **Production Bundle:** `index.html` at the repository root is the **compiled production bundle** generated by `vite-plugin-singlefile`.
   - NEVER manually overwrite `index.html` with `<script type="module" src="/src/main.tsx"></script>`.
   - Never replace `index.html` with an uncompiled template.
3. **Automated Synchronization:** `vite.config.ts` uses `productionBundleSyncPlugin()` to automatically compile `index.source.html` into `dist/index.html` AND mirror it to root `index.html` on every `npm run build`.
4. **Verification Requirement:** Every code change or feature addition MUST be verified by running `npm run build` (or `compile_applet`) so that `index.html` is continuously refreshed with the latest features.
5. **Hosting Compatibility:** Maintain `.htaccess` and `.cpanel.yml` for Apache MIME types, routing, and Hostinger cPanel Git deployments.
