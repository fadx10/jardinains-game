# Jardinains Project Instructions

## Hosting and deployment

This project is hosted exclusively on **GitHub Pages**:

https://fadx10.github.io/jardinains-game/

Do not add FTP, Hostinger, cPanel, Apache, or DigitalPhablet deployment steps or credentials. GitHub Pages publishes the generated standalone bundle from the repository's `main` branch.

## Source and production HTML

1. `index.source.html` is the only source HTML template. Keep page metadata, canonical URL, fonts, and head configuration there.
2. Root `index.html` is the compiled standalone production bundle generated by `vite-plugin-singlefile`. Never manually replace it with raw source HTML or a script that loads uncompiled TSX.
3. `vite.config.ts` generates `dist/index.html` and synchronizes it to the repository root during `npm run build`.

## Required verification

After every code change or feature addition, run:

```bash
npm run lint
npm run build
```

The GitHub Actions workflow runs both checks and commits the generated root bundle for GitHub Pages.
